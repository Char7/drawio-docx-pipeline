# Generic sample

`three_steps.drawio` is an **original generic demo** (planning → creation → quality check) with Thai labels and editable draw.io objects on an explicitly white canvas. It contains no private project data or generated images.

Open it in diagrams.net, edit a box, export a white PNG with transparent background OFF, then inspect it at the intended print size. The SVG fallback is optional and must use a supported rendering tool; the validator does not export images.
